# تدريبات الأئمة والمؤذنين

منصة تدريب ذاتي للمتقدمين لاختبار الأئمة والمؤذنين: ملخصات للمقررات المعلنة، وبنك تمارين،
وأوراق تدريب كاملة تُصحَّح آلياً، وتتبُّع للأخطاء.

**الرابط:** https://alsawagh0-ui.github.io/imam-exam/

## إخلاء مسؤولية

هذا جهد شخصي للمذاكرة والتمرين، **وليس جهة رسمية ولا يتبع وزارة الأوقاف والشؤون الإسلامية
ولا أي جهة حكومية**، ولا يصدر عنها ولا يمثلها. الأسئلة فيه تمارين من إعداد القائمين عليه،
وليست أسئلة اختبار رسمية ولا تنبئ بأسئلة الاختبار. المرجع الملزم هو المقرر والإعلان
الصادران عن الجهة المختصة.

## الخصوصية

صفحة واحدة ساكنة بلا خادم وبلا قاعدة بيانات. تقدّمك وأخطاؤك تُحفظ في متصفحك وحده
(`localStorage`) ولا تُرسل إلى أي مكان.

## البناء

الصفحة المنشورة `index.html` مولَّدة. لتعديل المحتوى عدّل ما في `src/` ثم:

```
python3 src/build.py
```
